<p>搜“Claude 住宅 IP”，排在前面的十几个站点页面风格都差不多，都自称官方、都有套餐页、都能直接下单。真正决定后面几个月顺不顺的，不是首页做得多漂亮，而是四层信息能不能互相对上：谁在卖、卖的到底是什么网络、钱按什么口径算、出问题谁处理。这篇按这四层逐层给核对方法，每层写清查什么、去哪儿查、看到什么算过关、看到什么该追问，最后附一张可以照着填的核对表，供采购前自查使用。</p>

<h2>一、先把辨别对象说清楚</h2>
<p>“官网”这个词在住宅 IP 行业里没有统一含义。有人指自建线路并自己运维的服务商，有人指转售别家资源的代理平台，还有人只是做了个落地页、成交后转给上游。三类都能买到能用的资源，但承诺兑现的方式差别很大，核对的重点也不一样。</p>
<h3>自营、转售、纯引流怎么区分</h3>
<p>看三处：页面是否公布自有 ASN 与 IP 段、是否说明上游是谁、技术支持能否直接回答路由层面的问题。自营方通常能报出自己的 ASN 号和机房位置；转售方一般会承认上游，但能提供工单升级路径；纯引流方对“你的出口走哪条骨干”这类问题基本只会重复套餐页的话术。</p>
<h3>核对的目的不是找最正规的，而是找可追责的</h3>
<p>规模小的服务商也可能线路质量很好。判断标准应该落在“出问题能不能找到具体的人、能不能按条款处理”，而不是公司多大。一个能给出具名技术对接人、能承诺替换时限的小团队，实际体验往往优于只有在线客服机器人的大平台。</p>

<h2>二、第一层：主体与资质，能查到的才算数</h2>
<p>这一层的动作最机械，也最容易被跳过。花十分钟做完，能过滤掉相当一部分临时站点。</p>
<h3>主体信息要求三处对齐</h3>
<p>把页面底部或“关于我们”里的公司全称，分别拿去域名 whois、备案或工商信息查询入口、收款账户主体三处比对。三处一致是最低要求。域名注册时间不足半年、whois 开了隐私保护、收款方是个人账户，这三条同时出现时，建议直接放弃，不用再往下看套餐。</p>
<h3>资质只看可验证的部分</h3>
<p>常见的有 IDC/ISP 相关许可、自有 ASN、IP 段归属。ASN 可以在 bgp.he.net 或 ipinfo.io 上按号查，能看到该号下宣告的网段和上游运营商；IP 段归属可以在 whois 里反查组织名。宣传页写“持牌经营”但查不到任何号的，属于无法验证的表述，采购文件里不应作为依据。</p>

<h2>三、第二层：节点说明，看可核对项而不是形容词</h2>
<p>节点说明是最容易注水的一段。“覆盖全球”“原生住宅”“双 ISP 纯净”这些词本身没有错，问题在于它们都是结论，不是证据。核对的办法是把结论翻译成可以查的字段。</p>
<h3>地区覆盖要落到城市与 ASN</h3>
<p>要求对方给出可分配的城市清单，而不是国家数量。拿到清单后抽三个城市各取一条测试地址，用 ipinfo.io 或 ipapi 查 city、region、ASN 三项，看是否与清单一致。宣传“覆盖五十国”、实际可分配住宅出口只有十来个，是行业里比较常见的落差，抽查就能发现。</p>
<h3>住宅属性要能自证</h3>
<p>可查的字段有三个：ipinfo 返回的 type 或 usage_type、ASN 的持有者类型（家宽运营商还是云厂商）、公开滥用记录查询结果。三项都指向消费级宽带，才算站得住。若 ASN 属于常见云厂商，即便页面写“住宅”，实际也是机房出口换了说法，风控侧的判定不会因为文案而改变。</p>

<h2>四、第三层：价格透明度，四处必须写明</h2>
<p>价格页最考验服务商的诚实程度。透明不是指便宜，而是指把所有可能产生费用的地方提前写出来，让你能自己算出一个月到底花多少。</p>
<h3>计费维度写没写全</h3>
<p>住宅 IP 的报价通常挂在四个维度上：流量（每 GB）、并发或连接数、端口数量、独享程度。只写月费不写这四个维度的报价单，等于没报价。反过来，四个维度都写清、并给出超额单价和计费颗粒度的，基本可以按数字横向比价。</p>
<h3>把隐性成本单列出来</h3>
<p>初装费、换 IP 费、超额流量单价、暂停期间的保留费、跨区调换费，这五项是最常见的追加项。签约前让对方在报价单上逐项写“有/无”和金额，比事后争论有效得多。下面这张表是报价单里几种典型写法与实际含义的对照。</p>

<h2>五、第四层：支持与合同，出事时谁负责</h2>
<p>前三层决定能不能买，这一层决定买完之后难不难受。住宅 IP 是长周期服务，几个月里遇到线路调整、地址变更、账号异常几乎是必然的，处理效率比初始价格重要。</p>
<h3>故障响应要落到条款</h3>
<p>问三个具体问题：工单首次响应多久、线路中断是否按小时折算补偿、是否有非工作时间的值班渠道。回答含糊的，基本可以预期出事时只能等。把这些写进合同附件，比口头承诺有用。</p>
<h3>替换与退款规则要能量化</h3>
<p>常见规则是“IP 不可用可换”，但“不可用”由谁判定、多久内换、换几次以内免费，才是关键。建议约定：连续两次连通性测试失败即可申请替换，24 小时内完成，单月免费替换不少于两次。量化之后，纠纷会少很多。</p>

<h2>常见问答</h2>
<h3>首页写着“官方直营”就可以信吗？</h3>
<p>答：不能只凭这四个字。官方与否要靠 ASN、IP 段归属、主体信息来印证，文案谁都能写。核对顺序建议是先查主体和网段，再看节点清单，最后看价格口径，三层都过再谈下单。</p>
<h3>没有境内备案的境外服务商能不能买？</h3>
<p>答：能不能买取决于你的业务合规要求和付款结算方式，不取决于有没有备案。需要留意的是合同主体、发票开具、争议管辖这三项是否清楚，以及数据出境是否符合你所在行业的要求，这些要在采购前和法务确认。</p>
<h3>节点说明只写“覆盖全球 50 国”怎么办？</h3>
<p>答：直接要城市级清单和 ASN。给不出来就先小规模试用，用 ipinfo 抽查三个城市的 city、region、ASN 三项，一致率低于八成说明清单不可靠，此时价格再低也要谨慎。</p>
<h3>价格表里的“起”字怎么理解？</h3>
<p>答：通常对应最低配置，也就是单 IP、最低带宽、共享出口。比价时必须把配置拉到同一档再比，否则最低配的价格和独享套餐放在一起看，结论一定是错的。</p>
